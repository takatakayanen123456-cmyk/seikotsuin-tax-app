Google スプレッドシート自動転送設定 (GAS)

クラウド（Googleスプレッドシート）への自動保存・リアルタイム同期機能

おすすめ：GAS連携を設定しておくと、入力するたびに自動でGoogleスプレッドシート（クラウド上）へ保存されるため、スマホの故障やアプリ削除時もデータが安全に保護されます。

導入手順（5分で完了）

  1. Googleスプレッドシートを新規作成します。
  2. メニューの 「拡張機能」 > 「Apps Script」 を開きます。
  3. 表示されたコードエディタに、下記のスクリプトをすべてコピー＆ペーストします。
  4. 右上 「デプロイ」 > 「新しいデプロイ」 をクリック。
  5. 種類を 「ウェブアプリ」 に選択し、アクセスできるユーザーを 「全員 (Anyone)」 に変更してデプロイします。
  6. 発行された 「ウェブアプリ URL」 をコピーして、上記の入力欄に貼り付けて保存してください。

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["ID", "日付", "借方科目", "金額", "貸方科目", "摘要"]);
  }
  
  sheet.appendRow([
    data.id,
    data.date,
    data.debit,
    data.amount,
    data.credit,
    data.desc
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}

データ保存と複数端末のご利用について

安心してご利用いただくために

  • 端末内保存（初期状態）: 入力データはお使いの端末（ブラウザ）内に保存されます。キャッシュ消去やアプリ削除の前に「仕訳帳」タブからバックアップ保存を行ってください。
  • PC・スマホのデータ共有: パソコンとスマホなど複数の端末で同じ帳簿データをリアルタイム同期したい場合は、「GAS連携」を設定していただくと大変便利です。

画面上の「GAS連携」タブから簡単にGoogleスプレッドシートへの無料自動同期を設定できます。

レセコンCSV取込 使い方ガイド

レセコン（メディカルランド、互助会、補正システム等）から出力した月次・日次売上CSVを取り込むことで、日々の手入力を省略して自動で複式簿記の仕訳を作成できます。

簡単4ステップの流れ

1

レセコンから売上CSVを出力

お使いのレセコンソフトの管理画面から「集計データ」「売上データ」「月報」等のCSVファイルをダウンロードします。

2

ファイルを選択

「1. レセコン売上CSVファイルを選択」ボタンから出力したCSVファイルを選択します。

3

列の紐付け（マッピング）

自動検出されたCSVの項目名の中から、「日付」「窓口収入」「保険請求額」に該当する列を選択します。

4

一括インポートを実行

「一括インポートを実行する」を押すと、指定した列の内容で自動的に複式仕訳が作成され仕訳帳に登録されます。

安心ポイント

  • 和暦（例: R6.9.25、令和6年9月25日）や「2026/09/25」形式も自動認識されます。
  • 窓口売上は「現金／保険窓口売上」、請求額は「未収療養費／療養費売上」として自動で適切な勘定科目で記帳されます。

GAS連携（スプレッドシート自動同期）ガイド

なぜGAS連携をおすすめするのか？

本アプリの通常データはご使用の端末内にのみ保存されます。GAS連携（Google Apps Script）を設定すると、仕訳を登録した瞬間にGoogleスプレッドシート（クラウド）へ自動保存されるため、PCとスマホ間でのデータリアルタイム共有や、故障・機種変更時の100%安全なデータ保護が実現できます。

導入5ステップ（5分で完了）

1

Googleスプレッドシートを準備

Googleドライブを開き、新規で「スプレッドシート」を作成します（ファイル名は自由です）。

2

Apps Script を起動

上部メニューの「拡張機能」>「Apps Script」をクリックしてエディタを開きます。

3

コードをコピー＆ペースト

アプリ内の「コードをコピー」ボタンを押し、表示されている既存コードを全て上書きで貼り付けます。

4

ウェブアプリとしてデプロイ

「デプロイ」>「新しいデプロイ」を選択し、種類を「ウェブアプリ」、アクセスできるユーザーを「全員 (Anyone)」に設定して完了します。

5

URLをアプリに設定

発行された「ウェブアプリ URL」をコピーし、本アプリの「GAS WebアプリURL」欄に貼り付けて設定保存します。

補足と安心ポイント

  • 初回デプロイ時にGoogleからアクセス許可（承認）を求められる場合は「詳細」>「安全ではないページに移動」から許可を行ってください。
  • 「仕訳追加時にリアルタイム自動転送する」をチェックしておくと、登録のたびに背景でスプレッドシートに追記されます。
